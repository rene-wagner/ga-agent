# Aufgaben sammeln

Verwende diesen Skill, wenn aus unstrukturierten Notizen eine Aufgabenliste
entstehen soll.

1. Identifiziere konkrete Aufgaben und trenne sie von allgemeinen Informationen.
2. Formuliere jede Aufgabe als ausführbaren nächsten Schritt.
3. Übernimm Verantwortliche und Termine nur, wenn sie ausdrücklich genannt werden.
4. Kennzeichne fehlende Informationen, statt sie zu erfinden.
5. Verwende das Format aus [references/output-format.md](references/output-format.md).
